### 第一步：定义请求和响应模型

```
schemas.py
from pydantic import BaseModel, Field


class AskRequest(BaseModel):
    question: str = Field(min_length=1, max_length=1000)
    top_n: int = Field(default=5, ge=1, le=20)
    top_k: int = Field(default=3, ge=1, le=10)


class SourceItem(BaseModel):
    chunk_id: str
    text: str
    dense_score: float
    rerank_score: float | None = None


class AskResponse(BaseModel):
    question: str
    answer: str
    sources: list[SourceItem]
    latency_ms: float
```

你今天要注意一个重要变化：

> 你的系统输出不再只是 `str`，而是一个有固定字段、可被前端和其他程序消费的 API 响应。

        # 这些对象应当在服务启动时初始化一次。
        self.chunks = ...
        self.embedding_model = ...
        self.index = ...
        self.reranker = ...

    def ask(self, question: str, top_n: int = 5, top_k: int = 3):
        start = time.perf_counter()

        dense_results = self._dense_retrieve(
            question,
            top_n=top_n,
        )

        reranked_results = self._rerank(
            question,
            dense_results,
            top_k=top_k,
        )

        context = self._build_context(reranked_results)
        answer = self._generate_answer(question, context)

        latency_ms = round(
            (time.perf_counter() - start) * 1000,
            2,
        )

        return {
            "question": question,
            "answer": answer,
            "sources": reranked_results,
            "latency_ms": latency_ms,
        }
```

### 第三步：创建 FastAPI 后端

```
api.py
from fastapi import FastAPI, HTTPException

from rag_service import RAGService
from schemas import AskRequest, AskResponse


app = FastAPI(
    title="Mini RAG Service",
    version="0.1.0",
    description="A minimal RAG API with retrieval, reranking and citations.",
)

service = RAGService()


@app.get("/health")
def health():
    return {
        "status": "ok",
        "service": "mini-rag",
    }


@app.post("/ask", response_model=AskResponse)
def ask(request: AskRequest):
    try:
        result = service.ask(
            question=request.question,
            top_n=request.top_n,
            top_k=request.top_k,
        )
        return result

    except ValueError as error:
        raise HTTPException(
            status_code=400,
            detail=str(error),
        ) from error

    except Exception as error:
        raise HTTPException(
            status_code=500,
            detail=f"Internal error: {error}",
        ) from error
```

### 第五步：制作 Gradio 展示层

```
ui.py
import requests
import gradio as gr


API_URL = "http://127.0.0.1:8000/ask"


def ask_rag(message: str, history):
    response = requests.post(
        API_URL,
        json={
            "question": message,
            "top_n": 5,
            "top_k": 3,
        },
        timeout=60,
    )

    response.raise_for_status()
    data = response.json()

    source_text = "\n\n".join(
        f"[{source['chunk_id']}] {source['text']}"
        for source in data["sources"]
    )

    return (
        f"{data['answer']}\n\n"
        f"---\n"
        f"Sources:\n{source_text}\n\n"
        f"Latency: {data['latency_ms']} ms"
    )


demo = gr.ChatInterface(
    fn=ask_rag,
    title="Mini RAG Knowledge Assistant",
    description="Ask questions based on the indexed document.",
    examples=[
        "What is the main purpose of this document?",
        "What practical steps are recommended?",
        "Which part is most relevant to a beginner?",
    ],
)


if __name__ == "__main__":
    demo.launch()
```

启动顺序：

```
# 终端 1
fastapi dev api.py

# 终端 2
python ui.py
```

Gradio 官方文档的 `ChatInterface` 适合快速将函数包装成聊天网页；今天只用最小能力，不要增加账户、数据库和复杂前端状态管理。[Gradio](https://www.gradio.app/docs/gradio/chatinterface?utm_source=chatgpt.com)

```

  {

    "top_n": 5,
    "top_k": 3
  }
]
```

你今天不需要做严格性能工程，但要观察：

- 第一次请求是否明显更慢；
- 模型加载是否被错误地放在每次请求中；
- `top_n` 从 5 调到 10 后，延迟是否增加；
- reranker 是否占据主要时间。
