## 2. 必须理解的概念

- List 与 tuple：可变性不同；选择取决于语义和使用方式。
- Dict / set：哈希查找与唯一性。
- Mutable default：不要用可变对象作为函数默认参数。
- Generator：惰性地产生数据，适合大数据流。
- Iterator：实现迭代协议的对象。
- Context manager：用 `with` 管理资源生命周期。
- Exception：捕获可处理的具体异常，不要用宽泛捕获掩盖错误。
- Async I/O：适合等待 I/O，不等于 CPU 并行。
