## Day 2｜HTTP + API：让 Python 真正调用一次 AI

今天的目标不是“看懂 API 文档”，而是完成一条完整链路：

```
Python 程序
→ 发出 HTTPS 请求
→ API 服务器验证 API Key
→ 模型生成结果
→ 返回 JSON
→ Python 解析并打印答案
```

今天只学这几个概念：**URL、HTTP 方法、请求头、JSON、状态码、API Key、timeout、异常处理**。

### 今天最值得看的 3 个材料

1. **DeepSeek 官方 Chat Completions 文档**
   这是你今天最核心的材料。重点只看：`POST /chat/completions`、`messages`、`model`、`Authorization`、返回值里的 `choices[0].message.content`。官方文档还明确展示了 `200` 成功响应、`usage` 用量信息和工具调用相关结构。[DeepSeek API Docs](https://api-docs.deepseek.com/api/create-chat-completion/?utm_source=chatgpt.com)
2. **Requests 官方 Quickstart**
   只看这些部分：`requests.post()`、`headers`、`json=`、`timeout`、`response.json()`、`raise_for_status()`。你今天不需要把 Requests 全学完，只需要学会用 Python 发送一次可靠的 POST 请求。[DeepSeek API Docs](https://api-docs.deepseek.com/api/create-chat-completion/?utm_source=chatgpt.com)
3. **MDN HTTP 状态码**
   今天重点记住：
   `200` 成功，`400` 请求写错，`401` 身份验证失败，`429` 请求过多，`500` 服务端错误。MDN 将状态码分为 1xx、2xx、3xx、4xx、5xx 五类。[MDN Web Docs](https://mdn.go-mizu.dev/zh-CN/docs/Web/HTTP/Reference/Status?utm_source=chatgpt.com)

DeepSeek 目前的官方 API 文档页面仍然以 `chat/completions` 为核心接口；不要直接照搬搜索结果里第三方网站的模型名或参数，优先以官方 API 文档为准。[DeepSeek API Docs](https://api-docs.deepseek.com/api/create-chat-completion/?utm_source=chatgpt.com)

### 3. 编写 `main.py`

```
import os
import requests
from dotenv import load_dotenv

load_dotenv()

api_key = os.getenv("DEEPSEEK_API_KEY")

if not api_key:
    raise RuntimeError("找不到 DEEPSEEK_API_KEY，请检查 .env 文件")

url = "https://api.deepseek.com/chat/completions"

headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json",
}

payload = {
    "model": "deepseek-flash",
    "messages": [
        {
            "role": "user",
            "content": "用一句话解释什么是 HTTP API。",
        }
    ],
    "stream": False,
}

try:
    response = requests.post(
        url,
        headers=headers,
        json=payload,
        timeout=30,
    )

    response.raise_for_status()

    data = response.json()
    answer = data["choices"][0]["message"]["content"]

    print("模型回复：")
    print(answer)

except requests.exceptions.Timeout:
    print("请求超时，请检查网络或稍后重试。")

except requests.exceptions.HTTPError as error:
    print("HTTP 请求失败：", error)
    print("服务器返回：", response.text)

except requests.exceptions.RequestException as error:
    print("网络请求失败：", error)

except KeyError:
    print("返回 JSON 的结构和预期不一致：")
    print(response.text)
```

本课使用当前官方推荐的模型标识 `deepseek-flash`。旧标识 `deepseek-v4-flash` 虽暂时兼容，但对应旧模型已退役，新项目不要再使用旧名称；模型名和价格都应以官方文档为准。官方文档当前的 API 参考页会显示可用模型和请求结构。[DeepSeek API Docs](https://api-docs.deepseek.com/api/create-chat-completion/?utm_source=chatgpt.com)

## 今天的验收标准

今天完成后，你应该能独立回答：

1. `POST` 是什么意思？
2. URL、headers、body 分别是什么？
