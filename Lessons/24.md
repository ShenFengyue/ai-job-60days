### 第二步：创建 `app.py`

下面的代码假设你已经有昨天的 `schemas.py`，其中定义了 `AgentResponse`。

```
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field, ValidationError

from schemas import AgentResponse

# 按你项目中的实际文件名和函数名修改这一行
from agent import run_agent


app = FastAPI(title="RAG Agent API", version="1.0.0")


class ChatRequest(BaseModel):
    question: str = Field(min_length=1, max_length=4000)


@app.get("/health")
def health():
    return {"status": "ok"}


@app.post("/chat", response_model=AgentResponse)
def chat(request: ChatRequest):
    # 调用已有的 Agent，不要重新实现一套
    raw_result = run_agent(request.question)

    try:
        return AgentResponse.model_validate(raw_result)
    except ValidationError as exc:
        raise HTTPException(
            status_code=502,
            detail="Agent returned an invalid response",
        ) from exc
```

注意：`from agent import run_agent` 是根据之前的项目设计写的示例。如果你的文件名或函数名不同，修改这一行即可。如果 `run_agent` 返回的是字符串而不是字典或 `AgentResponse`，你还需要先将它转换成符合 `AgentResponse` 的结构。

这段代码完成三件事：

1. 检查用户输入是否合法。
2. 调用已有 Agent。
3. 验证输出，避免把不符合约定的数据当成正常结果返回。

这里的 `502` 用于表示 Agent 返回的数据不符合预期；其他未处理的内部异常仍可能产生服务器错误，后续再完善统一异常处理。

### 第五步：为 API 编写自动化测试

创建 `test_api.py`：

```
import app as app_module

from fastapi.testclient import TestClient


client = TestClient(app_module.app)


def test_health():
    response = client.get("/health")

    assert response.status_code == 200
    assert response.json() == {"status": "ok"}


def test_chat_success(monkeypatch):
    def fake_agent(question):
        return {
            "status": "answered",
            "answer": "RAG combines retrieval with generation.",
            "sources": ["doc_01"],
            "needs_human_review": False,
        }

    monkeypatch.setattr(app_module, "run_agent", fake_agent)

    response = client.post(
        "/chat",
        json={"question": "What is RAG?"},
    )

    assert response.status_code == 200
    assert response.json()["status"] == "answered"


def test_empty_question():
    response = client.post(
        "/chat",
        json={"question": ""},
    )

    assert response.status_code == 422


def test_missing_question():
    response = client.post("/chat", json={})

    assert response.status_code == 422


def test_invalid_agent_output(monkeypatch):
    monkeypatch.setattr(
        app_module,
        "run_agent",
        lambda question: {"status": "unknown"},
    )

    response = client.post(
        "/chat",
        json={"question": "Test"},
    )

    assert response.status_code == 502
```

这里使用 `monkeypatch` 临时替换 Agent，避免测试时真的调用模型 API。这样即使没有网络、API 余额不足或模型服务不可用，接口测试仍然可以运行。

运行：

```

```

### 两道面试题

**Q1：FastAPI 和直接调用 Python 函数有什么区别？**

答题思路：Python 函数只能在能够导入并执行该代码的环境中直接调用；API 则通过 HTTP 暴露统一接口，让其他语言、进程或设备也能调用。API 还可以提供输入验证、错误响应和自动生成的接口文档。

**Q2：为什么 API 测试时要 Mock 大模型调用？**

答题思路：模型调用可能受网络、费用、延迟和模型输出随机性影响。Mock 可以独立测试接口的输入验证、响应格式和错误处理；真正的模型行为则由集成测试和 Agent Evaluation 检查。两者互相补充。
