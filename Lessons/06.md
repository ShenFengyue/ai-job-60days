### 材料 1：DeepSeek 官方 JSON Output 文档

这是今天最重要的材料，因为你前几天使用的就是 DeepSeek API。官方明确要求：

- `response_format` 设置为 `{"type": "json_object"}`
- system 或 user prompt 中必须出现 `json`
- 最好提供目标 JSON 示例
- `max_tokens` 不合理时可能导致 JSON 被截断
- API 可能偶尔返回空 content，需要在代码中处理

这些不是理论，而是你今天要直接写进程序的工程约束。[DeepSeek API Docs](https://api-docs.deepseek.com/guides/json_mode/?utm_source=chatgpt.com)

### 第二步：定义数据模型

`models.py`：

```
from pydantic import BaseModel, Field


class WordCard(BaseModel):
    word: str = Field(min_length=1)
    meaning: str = Field(min_length=1)
    examples: list[str] = Field(min_length=1, max_length=3)
    mnemonic: str = Field(min_length=1)
    related_words: list[str] = Field(default_factory=list, max_length=5)
```

这里你要观察一个重要变化：

以前你只是“希望模型返回这些字段”；现在你是在代码中**明确规定这些字段必须存在，而且类型必须正确**。

### 第三步：修改 API 请求，让模型输出 JSON

`main.py`：

```
import json
import os
from pathlib import Path

import requests
from dotenv import load_dotenv
from pydantic import ValidationError

from models import WordCard

load_dotenv()

API_KEY = os.getenv("DEEPSEEK_API_KEY")
URL = "https://api.deepseek.com/chat/completions"
MODEL = os.getenv("DEEPSEEK_MODEL", "deepseek-v4-flash")

if not API_KEY:
    raise RuntimeError("缺少 DEEPSEEK_API_KEY")

word = input("输入一个英文单词：").strip()

system_prompt = """
You are an English vocabulary teacher.

Return JSON only.
The JSON object must contain exactly these fields:
- word: string
- meaning: string
- examples: array of 1 to 3 strings
- mnemonic: string
- related_words: array of strings

Example:
{
  "word": "abandon",
  "meaning": "放弃；遗弃",
  "examples": ["He abandoned the plan."],
  "mnemonic": "把 a band on 想成把乐队放在一边。",
  "related_words": ["give up", "desert"]
}
"""

payload = {
    "model": MODEL,
    "messages": [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": f"Please explain the word: {word}"}
    ],
    "response_format": {"type": "json_object"},
    "temperature": 0.2,
    "max_tokens": 500,
    "stream": False,
}

response = requests.post(
    URL,
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json=payload,
    timeout=30,
)

response.raise_for_status()
data = response.json()

raw_content = data["choices"][0]["message"].get("content")

if not raw_content:
    raise RuntimeError("模型返回了空 content")

try:
    parsed_json = json.loads(raw_content)
except json.JSONDecodeError as error:
    print("JSON 解析失败：", error)
    print("原始返回：", raw_content)
    raise

try:
    word_card = WordCard.model_validate(parsed_json)
except ValidationError as error:
    print("Pydantic 校验失败：")
    print(error)
    print("解析后的 JSON：", parsed_json)
    raise

result = word_card.model_dump()

print(json.dumps(result, ensure_ascii=False, indent=2))

Path("results.json").write_text(
    json.dumps(result, ensure_ascii=False, indent=2),
    encoding="utf-8",
)
```

### 第五步：写一个最小重试机制

今天不需要做复杂的自动修复，但你必须实现一次简单重试：

```
def validate_with_retry(raw_content: str, max_retries: int = 2):
    for attempt in range(max_retries + 1):
        try:
            parsed = json.loads(raw_content)
            return WordCard.model_validate(parsed)
        except (json.JSONDecodeError, ValidationError) as error:
            if attempt == max_retries:
                raise RuntimeError(
                    f"结构化输出连续失败 {max_retries + 1} 次"
                ) from error
            print(f"第 {attempt + 1} 次校验失败，准备重试：{error}")
            # 实际项目中这里应重新请求模型，而不是只重复本地解析
```

注意：这个版本只演示“校验循环”。真正的生产代码应该在失败后重新发起带有错误反馈的模型请求。
