## Tool 1：Calculator

```
tools.py
def calculator(a: float, b: float, operation: str) -> float:
    """
    Perform a basic arithmetic operation.

    Args:
        a: First number.
        b: Second number.
        operation: One of add, subtract, multiply, divide.
    """
    if operation == "add":
        return a + b

    if operation == "subtract":
        return a - b

    if operation == "multiply":
        return a * b

    if operation == "divide":
        if b == 0:
            raise ValueError("Cannot divide by zero.")
        return a / b

    raise ValueError(f"Unsupported operation: {operation}")
```

        "parameters": {
            "type": "object",
            "properties": {

                    "type": "string"
                }
            },
            "required": [
                "query"
            ]
        }
    }
]
```

这里你需要真正理解：

> LLM 并不是直接“运行 Python 函数”。

它实际上只是产生一个**结构化的调用意图**：

```
{
  "name": "calculator",
  "arguments": {
    "a": 123,
    "b": 456,
    "operation": "multiply"
  }
}
```

然后**你的程序**负责执行。

# 5）实现 Tool Router

```
agent.py
```

核心逻辑：

```
def execute_tool(name: str, arguments: dict):
    if name == "calculator":
        return calculator(**arguments)

    if name == "search_knowledge":
        return search_knowledge(**arguments)

    raise ValueError(f"Unknown tool: {name}")
```

然后建立：

```
LLM
 ↓
tool_call?
 ↓
execute_tool()
 ↓
tool_result
 ↓
LLM
 ↓
final_answer

### 最重要的验收问题

如果面试官问：

> **“Agent 和普通 LLM API 调用有什么区别？”**

你应该能回答：

> 普通 LLM 调用通常是用户输入到模型输出；Agent 则允许模型根据任务决定是否采取行动，并通过工具获得外部信息或执行操作。程序负责执行工具并把结果重新放入上下文，模型再根据新的 observation 决定下一步或者生成最终答案。

如果这句话你能真正理解，而不是背下来，**Day 30 就过关。**

## 今日面试题

### 题 1

**为什么 Agent 不能直接让 LLM 执行 Python 函数？**

核心答案：

> LLM 本身只是生成文本或结构化调用请求。真正执行函数的是宿主程序。这样可以控制权限、参数校验、错误处理和安全边界。

### 题 2

**如果 Agent 一直调用错误的工具，你怎么排查？**

按这个顺序：

```
Tool description
↓
Tool schema
↓
参数定义
↓
Prompt
↓
模型本身的 tool-calling 能力
↓
测试集
```

不要第一反应就“换模型”。
