## Day 8｜Embeddings：把文本变成“可比较的语义向量”

今天是 **Day 8（2026 年 9 月 12 日）**。路线进入 RAG 基础阶段：先理解“文本如何变成向量”，再进入 Day 9 的向量检索。

今天不要学向量数据库，不要做完整 RAG，也不要开始微调。你今天只需要把这条链路跑通：

```
文本
→ embedding 向量
→ 相似度计算
→ 找到语义最接近的文本
```

Sentence Transformers 的官方定位就是生成句子、段落和图像的 dense embeddings，用于 semantic search、similarity、clustering 和 retrieval。[Hugging Face](https://huggingface.co/docs/hub/sentence-transformers?utm_source=chatgpt.com)

## 1）今日学习目标

完成今天后，你应该能：

- 解释 embedding 是什么；
- 说明为什么“语义相近”的句子，向量通常也更接近；
- 使用一个现成模型把文本编码成向量；
- 计算两个文本之间的相似度；
- 对一组候选文本做 top-k 语义搜索；
- 理解 embedding 模型只是“表示文本”，它本身不是聊天模型；
- 发现语义搜索的失败案例，而不是默认它总是正确。

今天只记住一个核心区别：

```
LLM：生成答案
```

### 第三步：编写语义搜索程序

`main.py`：

```
import json
from pathlib import Path

from sentence_transformers import SentenceTransformer, util


MODEL_NAME = "sentence-transformers/all-MiniLM-L6-v2"
DATA_PATH = Path("data.json")
OUTPUT_PATH = Path("results.json")


def load_data():
    return json.loads(DATA_PATH.read_text(encoding="utf-8"))


def main():
    records = load_data()
    texts = [record["text"] for record in records]

    model = SentenceTransformer(MODEL_NAME)
    document_embeddings = model.encode(
        texts,
        convert_to_tensor=True,
        normalize_embeddings=True,
    )

    queries = [
        "How does exercise affect mental health?",
        "What is a reusable unit of Python code?",
        "How do vector representations help search?",
    ]

    all_results = []

    for query in queries:
        query_embedding = model.encode(
            query,
            convert_to_tensor=True,
            normalize_embeddings=True,
        )

        scores = util.dot_score(
            query_embedding,
            document_embeddings,
        )[0]

        top_k = min(3, len(records))
        top_results = scores.topk(k=top_k)

        matches = []
        for score, index in zip(
            top_results.values.tolist(),
            top_results.indices.tolist(),
        ):
            matches.append(
                {
                    "id": records[index]["id"],
                    "text": records[index]["text"],
                    "topic": records[index]["topic"],
                    "score": round(float(score), 4),
                }
            )

        all_results.append(
            {
                "query": query,
                "matches": matches,
            }
        )

    OUTPUT_PATH.write_text(
        json.dumps(all_results, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )

    print(json.dumps(all_results, ensure_ascii=False, indent=2))


if __name__ == "__main__":
    main()
```

这里你要特别观察：

- `encode()` 得到的是向量；
- `normalize_embeddings=True` 让相似度更容易比较；
- `dot_score()` 用来给候选文本排序；
- top-k 只返回最接近的几条，而不是全部文本。

### 第四步：增加一个关键词对照实验

再增加一个非常简单的关键词搜索函数，和 embedding 搜索比较：

```
def keyword_search(query: str, records: list[dict]) -> list[dict]:
    query_words = set(query.lower().split())
    scored = []

    for record in records:
        text_words = set(record["text"].lower().split())
        overlap = len(query_words & text_words)
        scored.append((overlap, record))

    scored.sort(key=lambda item: item[0], reverse=True)
    return [record for score, record in scored[:3]]
```
