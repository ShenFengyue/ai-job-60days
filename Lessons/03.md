## Day 3｜Git 与 GitHub：把“本地写代码 → 云端保存”跑通

今天不是为了背 Git 命令，而是建立你以后每天都会重复的工作流：

```
GitHub 上的仓库
→ clone 到电脑
→ 在本地修改文件
→ Git 记录修改
→ push 回 GitHub
```

GitHub 官方明确说明：`git clone` 会把仓库完整复制到本地，同时建立名为 `origin` 的远程连接；之后你可以在本地修改，再把提交推送回 GitHub。[GitHub Docs](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository?utm_source=chatgpt.com)

### 1）今日学习目标

今天完成后，你应该能独立完成这 7 件事：

1. 在本地找到你的仓库；
2. 理解“工作区、暂存区、提交、远程仓库”；
3. 修改一个文件；
4. 查看修改内容；
5. 创建一次 commit；
6. 把 commit push 到 GitHub；
7. 从 GitHub 网页确认修改已经出现。

今天先不学复杂分支、合并、冲突解决。你现在最需要的是**单人开发的基本闭环**。

### 2）今天最值得看的 3 个材料

**材料 1：GitHub 官方《Cloning a repository》**
这是今天最重要的材料。只看“Code → HTTPS → clone”这部分，理解 `clone` 的实际作用，不要泛读整篇。[GitHub Docs](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository?utm_source=chatgpt.com)

**材料 2：GitHub 官方《Connecting to your code locally》**
它专门面向“以前只在网页上操作，现在第一次把代码拉到电脑”的人，内容包括安装 GitHub Desktop、登录、clone、用编辑器打开。对你当前阶段尤其合适，因为你还不熟悉本地工作流。[GitHub Docs](https://docs.github.com/en/get-started/start-your-journey/connecting-to-your-code-locally?utm_source=chatgpt.com)

**材料 3：GitHub 官方《Getting started with Git》**
今天重点看 commit 的定义：commit 是一个项目快照。你要建立的直觉是：**每完成一个有意义的小阶段，就做一个可回退的存档点。**[GitHub Docs](https://docs.github.com/en/get-started/learning-to-code/getting-started-with-git?utm_source=chatgpt.com)

补充说明：今天我建议你优先用 **GitHub Desktop** 完成流程，而不是一上来背命令行。GitHub 官方教程本身就提供了“创建分支、编辑文件、commit、push、发起 pull request”的图形化入门路径。[GitHub Docs](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop?utm_source=chatgpt.com)

### 3）必须完成的 coding practice

#### 第一步：clone 仓库

你有两种方式，今天选一种即可。

**方式 A：GitHub Desktop，推荐**

1. 安装并打开 GitHub Desktop；
2. 登录你的 GitHub 账号；
3. 点击 **File → Clone repository**；
4. 切换到 **URL**；
5. 填入：

```
https://github.com/ShenFengyue/ai-job-60days.git
```

1. 选择本地保存位置；
2. 点击 **Clone**；
3. 点击 **Open in Visual Studio Code**，或者直接用资源管理器打开仓库文件夹。

**方式 B：PowerShell**

```
cd D:\AI
git clone https://github.com/ShenFengyue/ai-job-60days.git
cd ai-job-60days
```

`D:\AI` 只是示例，你也可以换成别的文件夹。

#### 第三步：用 Git 观察变化

在仓库根目录打开 PowerShell，依次执行：

```
git status
git diff
git add exercises/day03-git/README.md
git status
git commit -m "Day 03: learn Git workflow"
git log --oneline -5
git push
```

你只需要先理解这些动作：

```
git status
= 查看当前有什么变化

git diff
= 查看具体改了什么

git add
= 把这次要保存的修改放进暂存区

git commit
= 创建一个本地存档

git push
= 把本地存档上传到 GitHub
```

GitHub 官方对 `git push` 的说明也是：把本地提交推送到远程仓库；常见形式是 `git push origin main`。[GitHub Docs](https://docs.github.com/en/enterprise-server@3.17/get-started/using-git/pushing-commits-to-a-remote-repository?utm_source=chatgpt.com)

#### 第四步：在网页确认结果

```

```

确认文件已经出现在 GitHub 上。
