# 5）把 Calculator 改成 smolagents Tool

```
smol_agent/tools.py
from smolagents import tool


@tool
def calculator(
    a: float,
    b: float,
    operation: str,
) -> float:
    """
    Perform a basic arithmetic operation.

    Args:
        a: First number.
        b: Second number.
        operation: One of add, subtract, multiply, divide.
    """

    if operation == "add":
        return a + b

    if operation == "subtract":
        return a - b

    if operation == "multiply":
        return a * b

    if operation == "divide":
        if b == 0:
            raise ValueError("Cannot divide by zero.")

        return a / b

    raise ValueError(
        f"Unsupported operation: {operation}"
    )
```

注意：

```
@tool
```

就是今天最重要的 API。

# 6）创建第一个 ToolCallingAgent

```
smol_agent/agent.py
```

核心结构：

```
from smolagents import (
    ToolCallingAgent,
    InferenceClientModel,
)

from tools import calculator


model = InferenceClientModel()

agent = ToolCallingAgent(
    tools=[calculator],
    model=model,
)

result = agent.run(
    "What is 123 multiplied by 456?"
)

print(result)
```

如果你的模型提供商 / API 配置与官方示例不同，**以当前 `smolagents` 官方文档的 model provider 配置为准**，不要为了追求代码一模一样而硬改环境。官方当前支持多种模型接入方式，包括 `InferenceClientModel`、`TransformersModel`、`LiteLLMModel` 和 OpenAI-compatible model。[Hugging Face](https://huggingface.co/learn/agents-course/en/unit2/smolagents/why_use_smolagents?utm_source=chatgpt.com)

# 9）今天必须搞懂一个关键概念：`Tool` 不只是函数

昨天：

```
def calculator(...):
    ...
```

今天：

```
Python Function
      ↓
   @tool
      ↓
smolagents Tool
      ↓
LLM 可理解、可调用
```

也就是说 framework 帮你处理了一部分：

```
function
 ↓
metadata
 ↓
schema
 ↓
tool registry
 ↓
agent
 ↓
model
 ↓
tool call
 ↓
execution
```

这就是**框架存在的意义之一**。

## 今日面试题

### 题 1

**为什么你已经会手写 Tool Calling，还要使用 smolagents？**

答：

> 手写让我理解底层机制；框架让我减少重复 orchestration 代码，并提供标准化的 Tool、Agent、Model 抽象。实际工程中我会根据复杂度决定是否使用框架，而不是为了使用框架而使用框架。

### 题 2

**`ToolCallingAgent` 和 `CodeAgent` 的核心区别是什么？**

答：

> `ToolCallingAgent` 让模型以结构化 JSON/text tool call 的方式指定工具和参数；`CodeAgent` 则让模型生成 Python code 来组织和执行行动。前者更接近传统 function calling，后者表达复杂多步操作更灵活，但执行代码也带来更高的安全要求。[Hugging Face](https://huggingface.co/docs/smolagents/reference/agents?utm_source=chatgpt.com)
