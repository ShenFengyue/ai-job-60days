# 6）今天的第一个指标：Task Success Rate

定义：

```
Task Success Rate
=
成功完成任务的 cases
/
全部 cases
```

例如：

```
17 / 20 = 85%
```

先不要搞复杂。

你的 evaluator 可以简单判断：

```
def check_answer(
    answer: str,
    expected_keywords: list[str],
) -> bool:

    return all(
        keyword.lower() in answer.lower()
        for keyword in expected_keywords
    )
```

------

# 7）第二个指标：Tool Selection Accuracy

例如：

```
Expected:
search_knowledge

Actual:
calculator
```

就是：

```
FAIL
```

定义：

```
Tool Selection Accuracy
=
正确选择工具的次数
/
需要工具的 cases
```

例如：

```
14 / 16 = 87.5%
```

这个指标对你特别重要。

因为你现在做的是 Agent。

不是单纯 chatbot。

------

# 8）第三个指标：Step Efficiency

昨天你已经记录：

```
steps
```

今天把它正式纳入评测。

例如：

| Case             | Steps |
| ---------------- | ----- |
| Calculator       | 1     |
| RAG              | 1     |
| RAG + Calculator | 3     |
| No Tool          | 1     |

计算：

```
Average Steps
```

注意：

> **Steps 越少不一定越好。**

例如：

```
1 step → 错
3 steps → 对
```

显然 3 steps 更好。

所以：

```
Task Success
+
Steps
```

必须一起看。

# 9）第四个指标：Latency

用 Python：

```
import time

start = time.perf_counter()

answer = agent.run(question)

latency = time.perf_counter() - start
```

记录：

```
{
  "latency_seconds": 3.84
}
```

最后算：

```
Average Latency
```

今天不要求精确到生产级。

你只是第一次建立：

> **质量 + 速度**

的概念。

Hugging Face 当前官方 Agent Evaluation 材料也把 latency 和 cost 列为核心生产指标。[Hugging Face](https://huggingface.co/learn/agents-course/en/bonus-unit2/what-is-agent-observability-and-evaluation?utm_source=chatgpt.com)

# 10）第五个指标：Error Rate

记录：

```
try:
    answer = agent.run(question)
    error = False
except Exception as e:
    answer = None
    error = True
```

然后：

```
Error Rate
=
failed runs
/
total runs
```

例如：

```
2 / 20 = 10%
```

### ② Offline Evaluation 和 Online Evaluation 有什么区别？

**Offline：**

```
固定测试集
↓
Agent
↓
自动评测
```

适合：

- 开发
- Regression
- CI/CD

**Online：**

```
真实用户
↓
Agent
↓
线上 trace / feedback
```

适合：

- 发现真实世界 bad cases
- 监控 drift
- 用户反馈
- 生产质量

Hugging Face 当前官方材料也明确建议二者结合，而不是二选一。[Hugging Face](https://huggingface.co/learn/agents-course/en/bonus-unit2/what-is-agent-observability-and-evaluation?utm_source=chatgpt.com)
