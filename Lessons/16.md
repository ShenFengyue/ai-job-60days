## Tool 1：Calculator

```
def calculator(a: float, b: float, operation: str) -> float:
    """
    Perform a basic arithmetic operation.

    Args:
        a: First number.
        b: Second number.
        operation: add, subtract, multiply, or divide.
    """

    if operation == "add":
        return a + b

    if operation == "subtract":
        return a - b

    if operation == "multiply":
        return a * b

    if operation == "divide":
        if b == 0:
            raise ValueError("Cannot divide by zero.")
        return a / b

    raise ValueError(f"Unsupported operation: {operation}")
```

# 4）定义 Tool Schema

这是今天真正要理解的部分。

创建：

```
TOOLS = [
    {
        "name": "calculator",
        "description": "Perform basic arithmetic.",
        "parameters": {
            "type": "object",
            "properties": {
                "a": {
                    "type": "number"
                },
                "b": {
                    "type": "number"
                },
                "operation": {
                    "type": "string",
                    "enum": [
                        "add",
                        "subtract",
                        "multiply",
                        "divide"
                    ]
                }
            },
            "required": [
                "a",
                "b",
                "operation"
            ]
        }
    },
    {
        "name": "get_weather",
        "description": "Get the weather information for a city.",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {
                    "type": "string"
                }
            },
            "required": [
                "city"
            ]
        }
    }
]
```

你需要理解：

```
description
     ↓
告诉模型“什么时候应该用这个工具”

parameters
     ↓
告诉模型“这个工具需要什么参数”

function
     ↓
真正执行事情
```

**这三个东西缺一个都可能让 Agent 变差。**

# 5）自己写 Tool Router

`agent.py`：

```
def execute_tool(name: str, arguments: dict):

    if name == "calculator":
        return calculator(**arguments)

    if name == "get_weather":
        return get_weather(**arguments)

    raise ValueError(f"Unknown tool: {name}")
```

然后建立最小流程：

```
User
 ↓
LLM
 ↓
tool_call
 ↓
execute_tool()
 ↓
tool_result
 ↓
LLM
 ↓
final answer
```

## 今日面试题

### ① Tool Calling 和普通 Prompt 有什么区别？

**关键词：**

```
Prompt
→ 生成答案

Tool Calling
→ 生成结构化行动请求
→ 程序执行
→ 返回结果
→ 再生成答案
```

### ② Tool description 为什么重要？

因为模型需要根据 description 判断：

> **什么时候应该调用这个工具，以及应该提供什么参数。**

Hugging Face 当前官方文档也明确强调，Tool 的描述质量会直接影响 Agent 能够完成的任务范围。[Hugging Face](https://huggingface.co/learn/agents-course/en/unit1/tools?utm_source=chatgpt.com)
