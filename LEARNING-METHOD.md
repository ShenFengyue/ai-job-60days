# Learning Method

## The rule

**20% learning, 80% building.**

Every concept must end in code.

## Daily loop

1. Read the minimum material needed for today's target.
2. Close the material and implement from memory.
3. Put the feature into the current project.
4. Break it intentionally.
5. Debug it.
6. Commit the working result.
7. Write a 3–5 sentence note explaining the concept in your own words.

## AI-assisted coding rule

Use coding assistants aggressively, but never paste code you cannot explain. Before committing, be able to answer:

- What does this code do?
- Why is it designed this way?
- What can fail?
- How would I test it?
- How would I change it next month?

## Done means

A day is complete only when its deliverable exists and works. Watching a video does not count.

## Fast feedback

From Day 15 onward, job applications and interview feedback are part of the curriculum. If an interview exposes a missing skill, move that topic into the next study block.
