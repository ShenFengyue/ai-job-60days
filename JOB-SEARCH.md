# AI Job Search

## Target roles

Primary:
- AI Application Engineer
- LLM Engineer
- AI Agent Engineer
- AI Developer
- AI Product Engineer
- AI Solutions Engineer

Secondary:
- AI Product Manager / Assistant PM with strong coding ability
- AI Product / Solutions roles at startups where shipping matters

## Application rule

Start on Day 15. Do not wait for the portfolio to be perfect.

### Daily baseline
- 5–10 targeted applications
- 1 project-based application tailored to the role
- 1 networking / recruiter action
- 30–60 minutes interview preparation

## What to show

The portfolio should prove:
1. You can call and control LLMs.
2. You understand RAG, retrieval, grounding and evaluation.
3. You can build tool-using agents.
4. You can expose AI pipelines through an API.
5. You can persist data and deploy an application.
6. You can debug and measure a system rather than only demo it.

## Project pitch

**ResearchAI:** academic PDF RAG with citations and retrieval evaluation.

**Research Agent:** tool-using research workflow with retrieval, web search and memory.

**XiaoYa 2.0:** AI psychology assistant with production-oriented architecture, persistent conversations, retrieval, tools and evaluation.

## Interview questions

### LLM
- What happens between a user message and an LLM response?
- What is a token and why does context length matter?
- When would you choose a smaller model?

### RAG
- Why use RAG instead of fine-tuning for changing knowledge?
- What makes a good chunk?
- Why can top-k retrieval fail?
- What does a reranker add?
- How would you evaluate retrieval separately from generation?
- How do you reduce unsupported answers?

### Agents
- What makes an agent different from a chatbot?
- How does tool calling work?
- How do you handle malformed tool arguments?
- How do you evaluate an agent?
- What happens when a tool times out?

### Engineering
- How would you handle 100x traffic?
- How would you cut LLM cost by 50%?
- Where would you cache?
- How do you protect API keys and user data?
